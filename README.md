# Mafia Night — مشروع الواجهة المقسّم

## هيكل المشروع

- `index.html` — هيكل الشاشات فقط.
- `css/tokens.css` — ألوان ومتغيرات التصميم.
- `css/app.css` — المكونات والتنسيقات الأساسية.
- `css/mobile.css` — تحسينات الهاتف وتخطيط المراحل.
- `js/storage.js` — حفظ أسماء اللاعبين والقوائم على الجهاز، وتصدير/استيراد نسخة JSON.
- `js/workflow.js` — مؤشر المراحل والتنقل المرئي.
- `js/roles.js` — تعريف الأدوار ورسومات SVG الخاصة بها.
- `js/app.js` — منطق المباراة والأدوار والمؤقتات والتصويت.
- `assets/noir-city.webp` — صورة الواجهة الرئيسية ومشهد التحضير.
- `assets/noir-night.webp` — خلفية بطاقة الدور ومشهد الليل.

## التشغيل

افتح `index.html` مباشرة في متصفح حديث. إذا منع المتصفح التخزين المحلي عند فتح الملفات مباشرة، شغّل خادمًا محليًا داخل المجلد:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. ويمكن تشغيل `./run-local.sh` بدل كتابة الأمر يدويًا.

## حفظ أسماء اللاعبين

- تُحفظ الأسماء المفردة وآخر تشكيلة تلقائيًا باستخدام `localStorage` على نفس الجهاز والمتصفح.
- يمكن حفظ مجموعات أسماء بأسماء مختلفة مثل «أصدقاء المافيا» أو «العائلة».
- يمكن تنزيل نسخة JSON من الأسماء والقوائم واستعادتها لاحقًا من الملف.
- الأدوار السرية وبيانات المباراة لا تدخل في نسخة الأسماء الاحتياطية.

## سير المباراة

التحضير ← تسليم البطاقات ← الليل ← النهار ← التصويت ← الليلة التالية.
لا يوجد شريط تنقل سفلي يسمح بالقفز بين المراحل. أدوات اللاعبين والسجل تُفتح من زر «أدوات الحكم» أعلى الواجهة، ثم يمكن العودة إلى المرحلة الحالية.

## إضافة متحدث

في ترتيب المتحدثين يوجد زر `+`. عند الضغط عليه تظهر قائمة بأسماء اللاعبين الأحياء وغير المكتومين؛ يتم اختيار الاسم من القائمة ولا يحتاج الحكم إلى كتابته مرة أخرى. يمكن إضافة دور كلام إضافي للاعب ويظهر في نهاية ترتيب الحديث.

## ملاحظة

هذه نسخة واجهة ويب محلية وليست APK. التخزين المحلي خاص بالمتصفح والجهاز؛ استخدم ملف النسخة الاحتياطية لنقل قوائم الأسماء إلى جهاز آخر.


## ملفات JavaScript

- `storage.js` مستقل عن منطق المباراة، ويهتم بأسماء اللاعبين ونسخها الاحتياطية.
- `workflow.js` يرسم تقدم المراحل من دون السماح بالقفز إلى مرحلة لم تبدأ.
- `roles.js` يحتوي تعريفات الأدوار وأيقوناتها المتجهية.
- `app.js` ينسق المباراة ويربط الشاشات بهذه الوحدات.

لا توجد ملفات CSS أو JavaScript مضمنة داخل `index.html`؛ الصفحة تحتوي بنية الواجهة وتستدعي الملفات الخارجية.
